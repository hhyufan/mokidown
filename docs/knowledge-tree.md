# Markdown 知识树

Markdown 左侧会在存在知识树时显示「知识树」页签，支持展开、折叠和代码块跳转。透明标题工具栏右上角提供展开、折叠图标，外部 mgtree 另有打开树编辑器按钮；滚动长树时标题工具栏保持可见。侧栏、内嵌知识树与 mgtree 编辑器统一使用方框 `+ / −` 开关和连接线，普通节点不显示文件夹、文件图标，代码跳转节点保留代码图标与语言索引。分隔条支持拖动调整宽度，双击恢复 280px；聚焦分隔条后也可用左右方向键、Home、End 调整。宽度自动保存，移动端保持抽屉布局。

## 关联方式

对 `notes/课程.md`，依次寻找同目录的 `课程.mgtree`、`trees/课程.mgtree`，然后尝试以 Markdown 一级标题命名的同类文件。自动关联取首个非空文件。

也可以在 Markdown 中直接嵌入：

````markdown
```tree
课程
  第一个示例 >js[1]
  第二个示例 >js++
  再次查看第二个 >js
  跳过两个示例 >js+=2
```
````

`mgtree` 代码块与 `tree` 等价。外部引用支持相对 Markdown 的路径，可省略 `.mgtree` 后缀：

````markdown
```tree
@tree(trees/课程)
```
````

兼容旧项目的 `@tree(课程)`：先查同目录，未找到时再查 `trees/`。已在编辑器打开的树文件优先读取未保存内容，返回应用窗口时会重新读取外部文件。

## 跳转规则

索引从 1 开始，按语言单独计数：`>java[2]` 显式设置索引，`>java++` 加一，`>java+=3` 加三，`>java` 复用当前索引（首次为 1）。缩进表示父子关系，行内反引号内容保持代码样式。

树编辑器中点击节点文字原位编辑，行内代码保持渲染；输入反引号或选中文字按 Ctrl/Cmd+E 切换行内代码，行为与 Milkdown 一致。Enter 保存，Escape 取消。点击语言和序号标记可修改跳转语言、方式、序号或步进数量，也可取消跳转；普通节点悬停或聚焦后显示「添加代码跳转」入口。跳转设置独立于标题，修改文字不会丢失原有规则。

跳转按 Markdown 当前渲染顺序定位对应语言的代码块，兼容 `js/javascript`、`ts/typescript`、`py/python`、`c#/csharp`、`c++/cpp` 等别名。在 Milkdown 或分屏模式中跳转会保持当前模式，并在原视图滚动定位。代码块及点击的树节点使用约四秒的主题色变色和四周 1px 细边渐隐反馈，不显示侧边指示条；目录节点不保留选中背景。仅纯源码模式会打开分屏预览。不存在的目标会提示，保持原位置。
